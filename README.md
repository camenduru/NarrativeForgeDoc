# Narrative Forge Documentation

This repository contains the documentation for **Narrative Forge**, a data-driven
dialogue, quest and localisation toolkit for Unity.

The published documentation is available at:

**https://camenduru.github.io/NarrativeForgeDoc/**

## Local preview

```bash
python -m pip install mkdocs-material
mkdocs serve
```

Then open `http://127.0.0.1:8000`.

## Build

```bash
mkdocs build
```

The generated site is written to `site/`.

## Publishing

Pushes to `main` are built and deployed to GitHub Pages by
`.github/workflows/deploy.yml`.
