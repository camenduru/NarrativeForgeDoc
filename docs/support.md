# Support

Narrative Forge is published by **camenduru**.

## Contact

- **Email:** [unity@camenduru.com](mailto:unity@camenduru.com)
- **Website:** [camenduru.com](https://camenduru.com)
- **Documentation issues:** [github.com/camenduru/NarrativeForgeDoc/issues](https://github.com/camenduru/NarrativeForgeDoc/issues)

Use the issue tracker for documentation corrections and reproducible bugs. Use
email for account, licensing or private project questions.

## Before you write

Please include:

1. Unity version and target platform.
2. Narrative Forge version.
3. Whether you use the Asset Store package, tarball or an embedded copy.
4. The smallest JSON that reproduces the problem.
5. The full Console error or warning.
6. The steps to reproduce, and what you expected instead.

A small repro project or a minimal scene is the fastest way to get a useful
answer.

## Response expectations

Support is provided on a best-effort basis. Include enough detail to reproduce
the issue and avoid sending passwords, API keys or other secrets.

## Documentation feedback

If a page is unclear, missing an example or wrong, open an issue on the
documentation repository. Include the page URL and the section you are reading.
